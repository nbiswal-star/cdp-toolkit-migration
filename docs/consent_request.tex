\section{What we ask}
May the team send Collaborative Discussion Toolkit content to Claude, an AI model made by
Anthropic, for the uses listed below? You can say yes, yes with limits, or no.

\section{What would be sent, and when}
\begin{itemize}
  \item \textbf{Migration of the 46 existing activities: nothing.} Activities are copied by fixed
        code from your Wix pages. No AI is needed for this part.
  \item \textbf{Optional agent runs:} short summaries of each activity's checks (titles, step
        counts, any problems found) when the team runs the AI orchestrator instead of the fixed
        pipeline.
  \item \textbf{New or revised activities:} the full text of the activity document, when staff
        use the AI to format it for the website.
  \item \textbf{Never sent:} ratings, comments, names of people who commented, passwords, or
        anything from your WordPress site other than activity text.
\end{itemize}

\section{Accounts and data handling}
\begin{itemize}
  \item During the project: the team's own Anthropic account. After December 3: an account
        that IF holds, only if IF chooses to keep using the AI option.
  \item Anthropic's commercial terms and privacy policy apply. The team will attach the current
        summary of how Anthropic stores and uses API data, so IF can review it before deciding.
  \item The team keeps run files that contain activity text only on team computers, outside the
        code repository, and deletes them at handover.
\end{itemize}

\section{If IF says no}
Everything still works without AI: the fixed migration copies all activities, and staff add
new activities with the template and checklist. Only the optional AI formatting and the AI
orchestrator are not used.
