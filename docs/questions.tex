{\large\bfseries Client Meeting Prep: CDP Toolkit Migration}\hfill{\small Group 19 \textbullet{} Thursday, October 8, 2026}\\[-4pt]
\rule{\textwidth}{0.4pt}

\textbf{Client.} Interactivity Foundation (IF), Collaborative Discussion Project: Jes Friedrichs (sponsor), Rachael (requirements), Jasmine, Ellen; Jes to follow up with Shannon on the Website decision. Names to be confirmed with IF; shared only with IF and course staff.

\textbf{Problem as we understand it} (follow up to the October 1 requirements meeting). IF's open access Toolkit, 46 activities in five modules, each with a PDF, sits on Wix (collaborativediscussionproject.com), apart from the IF Website (interactivityfoundation.org, which appears to run WordPress). Two platforms cost money and split IF's content. IF chose to move the Toolkit to the Website, wants future updates to be easy while activities are being revised, and wants an agentic workflow that automates this work. We propose AI helpers that copy each activity faithfully as a draft for staff approval, plus a simple way to publish new ones.
